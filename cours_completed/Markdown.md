# Notes essentielles Markdown

## 1. C’est quoi Markdown ?

```text id="m1k8qp"
Markdown = langage de balisage léger pour formater du texte
```

```text id="c7v2tn"
Utilisé pour README, documentation, notes, blogs
```

---

## 2. Titres

```markdown id="t4x9kc"
# Titre 1
```

→ titre principal

```markdown id="m8v2qp"
## Titre 2
```

→ sous-titre

```markdown id="c3x7tn"
### Titre 3
```

→ sous-sous-titre

---

## 3. Texte

```markdown id="p9v1kc"
**gras**
```

→ met en gras

```markdown id="m2x8tn"
*italique*
```

→ met en italique

```markdown id="c6v1qp"
~~barré~~
```

→ texte barré

---

## 4. Listes

```markdown id="p7x2kc"
- élément
- élément
- élément
```

→ liste à puces

```markdown id="m4v7tn"
1. premier
2. deuxième
3. troisième
```

→ liste numérotée

---

## 5. Liens

```markdown id="k8x1qp"
[Google](https://google.com)
```

→ crée un lien cliquable

---

## 6. Images

```markdown id="n2v9tc"
![alt text](image.png)
```

→ affiche une image

---

## 7. Code

```markdown id="x7m3vp"
`code inline`
```

→ code sur une ligne

````markdown id="c1v8qn"
```js
console.log("Hello")
```

````

→ bloc de code

---

## 8. Tableaux

```markdown
| Nom | Age |
|-----|-----|
| Jean | 20 |
````

→ tableau

---

## 9. Citations

```markdown id="m9k4vp"
> Ceci est une citation
```

→ bloc de citation

---

## 10. Séparateurs

```markdown id="t3v7qn"
---
```

→ ligne horizontale

---

## 11. Listes imbriquées

```markdown id="p6x1tm"
- niveau 1
  - niveau 2
    - niveau 3
```

→ hiérarchie de listes

---

## 12. Checklists

```markdown id="m8v3qp"
- [x] fait
- [ ] à faire
```

→ liste de tâches

---

## 13. Emphase combinée

```markdown id="x2k7tn"
***gras + italique***
```

---

## 14. HTML dans Markdown

```markdown id="c9v1qp"
<b>HTML fonctionne aussi</b>
```

→ Markdown accepte parfois du HTML

---

## 15. Code block avec langage

````markdown id="r4x8tm"
```python
print("Hello")
```

````

→ coloration syntaxique

---

## 16. Rôle de Markdown

- écrire de la documentation
- structurer du texte simplement
- utilisé dans GitHub, Notion, docs techniques
- format standard pour README

---

## 17. Avantages

```text id="m1v6qn"
simple à écrire
````

```text id="p7x2tc"
lisible même en brut
```

```text id="m3v9qp"
compatible partout (GitHub, docs, etc.)
```

---

## 18. Résumé

Markdown = langage léger pour structurer du texte avec :

- titres
- listes
- liens
- code
- tableaux

👉 C’est le format standard de documentation moderne.
